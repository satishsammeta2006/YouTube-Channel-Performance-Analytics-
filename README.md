# YouTube Channel Performance Analytics (2025) 📊

## 📌 Overview
A **Power BI** dashboard analyzing 2025 performance data across **12 YouTube channels** and **96 videos** to track views, engagement, and monthly growth trends.

## 📈 Key Highlights
- **Total Views:** 1,195,202 | **Avg Views/Video:** 12,450
- **Total Likes:** 52,536 | **Total Comments:** 6,836
- **Engagement Rate:** 4.97% | **MoM Growth:** 7.74%
- **Top Channels:** *Style Compass* (Most Views: 175K) & *Home Chef Hub* (Most Likes: 7.75K)
- **Top Categories:** Technology & Food (0.23M views each)

- **Microsoft Power BI Desktop**
